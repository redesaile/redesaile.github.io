# User Website
This is a personal portfolio website. Below you can find instructions on how to compile the files and run it locally.

### Pre-requisites
1. Install **[Node.js](https://nodejs.org)**
2. Open Windows Command Prompt (`Win + R` -> `cmd`)

### How to compile SCSS
1. In Windows Command Prompt, type `npm install -g sass` to install [Sass compiler](https://www.npmjs.com/package/sass).
2. Run `compile-scss.cmd` from the root folder.
3. Save `.scss` file to trigger automatic compilation.

### How to minify JS
1. In Windows Command Prompt, type `npm install -g uglify-js` to install [UglifyJS minifier](https://www.npmjs.com/package/uglify-js).
2. Run `minify-js.cmd` from the root folder.

### How to run locally
This portfolio was developed using the **[Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)** extension by Ritwick Dey for [Visual Studio Code](https://code.visualstudio.com). You can run the site locally using its official documentation, or use any alternative software like [Open Server Panel](https://ospanel.io).
